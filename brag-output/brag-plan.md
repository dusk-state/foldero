# Brag plan — Foldero

## 9-question rubric

1. **What is the app?** A Claude Code / Cowork plugin that takes any messy folder tree — Downloads, a whole Documents root, a shared drive — and organises it: audits, plans a taxonomy, then moves files with verified, reversible, logged moves. Never deletes.

2. **Funniest/most impressive claim?** "21 skills. Never deletes. Every move verified." — a plugin that will fix your folder chaos but is structurally incapable of losing a file.

3. **Visual hook?** The landing page's terminal aesthetic: near-black bg (`#0B0D10`), electric cyan → violet gradient (`#3FC6FF` → `#9B5CFF`), monospace command labels, glowing accent lines. Reads as a dev tool, not a consumer app.

4. **What should be shown from the actual UI?** The landing page hero (`Take control of any folder tree.`), the terminal/command block styling, and the "Six guarantees" / skill-count stat block (21 skills, four groups).

5. **Shortest satisfying video?** 18 seconds. Enough to land: chaos → command → order → guarantee.

6. **Tone:** preset `deadpan` — direction: "a chaotic folder tree gets calmly, procedurally tamed by a command-line tool that refuses to ever delete anything." The comedy is the contrast between real folder chaos and the plugin's clinical, guarantee-driven confidence.

7. **Audio:** low, dry, slightly mechanical music bed (think terminal/hacker minimalism, not epic). One crisp keystroke/confirm SFX on the `/foldero` command reveal. Restrained — no swell, no fanfare, fade out clean.

8. **Share caption:** "Your Downloads folder has feelings. Foldero organises it anyway — 21 skills, zero deletions, every move verified. `/foldero` and go."

9. **User flow to show:** entry (a chaotic folder icon / messy tree) → key action (typing `/foldero` in a terminal, cyan/violet gradient sweeping in) → result (clean numbered pillar structure, "Six guarantees" stat line settling into frame).

## Music cue guidance

No bundled track pre-selected; Hyperframes to pick/detect a minimal, dry, low-key instrumental bed at composition time (no strings/epic swells — deadpan tone). Beat sync optional on the gradient-sweep (scene 3) and stat-settle (scene 4) moments only; readability and pacing stay primary over exact beat alignment.
